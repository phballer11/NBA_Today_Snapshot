Stats, data & install

Top five per team by Hollinger Game Score (GmSc). FG / 3PT / FT are made / attempted. Missing stats show “—”. If a box is incomplete, the table explicitly falls back to points.

Conference # positions use supplied ranks where reliable; otherwise they are computed from conference win percentage. “=” means a shared position; NBA tie-breaks are not applied. Positions reflect the latest fetched standings, including when viewing an older game.

Game notes are computed from box scores and available play-by-play, not editorial news. Run notes include the quarter and clock of their last score. The displayed game clock is a feed observation, not a running countdown.

ESPN is an unofficial public feed with no availability guarantee. Live pages refresh every 30 seconds; scheduled/final pages every two minutes, only while visible. Snapshot and cached fallbacks always show their age.

iPhone: open the GitHub Pages URL in Safari → Share → Add to Home Screen. Reopen from that icon for a full-screen view. Once opened online, the app and last viewed slates work offline.
