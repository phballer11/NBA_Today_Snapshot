# NBA Today

A lightweight, responsive snapshot of NBA games and scores, powered by ESPN's public scoreboard feed.

## Run locally

Serve this directory with any static web server. For example, with Python:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000). An internet connection is required to load scoreboard data from ESPN.

Use the date picker or arrow buttons to browse another day, and **Refresh** to reload the selected date.
